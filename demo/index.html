🎯 What You're Seeing

  • Stereoscopic Effect: Three frames with different vanishing points create depth illusion when alternating
  • FPS Control: Display refresh rate (how many times per second the engine ticks)
  • Hold Frames: How many FPS ticks before switching to next image
  • Effective Frequency: Actual alternation rate = FPS ÷ Hold (in Hz)
  • Render Modes: Fill (crop to fit), Fit/Contain (letterbox if needed)

💡 Try This

  • Set FPS to 60, Hold to 1 for maximum speed (60 Hz)
  • Set FPS to 60, Hold to 10 for stereoscopic effect (6 Hz)
  • Use Previous/Next to manually navigate frames
  • Switch between Fill and Fit modes to see the difference
